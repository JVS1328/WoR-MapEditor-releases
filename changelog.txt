- New maps: map menu > "New map from <Map>…" makes a copy of the open map, with your edits, under a new name (and the name players see). Install into game and Push to server carry it like the rest of the build; Delete in the same dialog removes it again. To change it, edit the map it came from and create it again under the same name.
- The New map dialog shows how to load it on your server: push it, restart the server, then switch with the console command Game.ChangeMap <Name> <Mode>, as an admin in game or over the server's RCON. Not tested in game yet.
- Install into game and Push skip files that haven't changed, so a new map (about 450 MB) is only sent once.
